## <a name='WhatisCboard'></a>图语家与 CBoard

图语家复用 CBoard 的沟通图板、图卡、编辑和朗读界面，并增加双向沟通、接收理解、常用语与本地草稿。图片及文字用于辅助沟通，不代表对方已经理解，也不能替代对方表达意愿。

本帮助对应当前图语家受限试用版本。可用功能以当前页面、账号权限和服务器提示为准；旧截图或其他 CBoard 版本的说明可能不同。

## <a name='Registrationandlogin'></a>账号、本机保存与同步

### <a name='HowdoIregisterforCboard'></a>如何注册？

当前版本保持受限试用，公开注册尚未开放。请使用已获授权的试用账号；不要因上游 CBoard 帮助中有注册说明，就认为本网站能够公开注册。

### <a name='CanIregistermyselfusingmysocialmediaaccounts'></a>能使用社交账号登录吗？

仅使用本版本登录页实际提供且已配置的入口。本帮助不承诺 Google、Facebook、微信扫码或短信登录已经开放。

### <a name='HowdoIlogintoCboardonceIamaregistereduser'></a>如何登录？

从设置中的账号入口打开登录页，使用自己的授权账号。家庭服务须选择有权限的档案；文字 AI 还须主动选择可用额度。登录成功不等于已获得这些权限，也不会自动调用模型。

### <a name='HowdoIlogout'></a>如何退出登录？

打开设置，使用当前账号旁的退出登录按钮。退出登录与清除本机资料是不同操作；更换账户或档案后，不应继续显示上一范围的私人内容。

### <a name='Whatisthedifferencebetweenaregisteredandanon-registereduser'></a>本机保存与账号同步有什么不同？

- “已保存到本机”只表示当前内容已按该功能的本机保存流程核验，不等于已同步到服务器或其他设备。
- 普通沟通历史、表达／接收草稿、常用语准备草稿有各自的本地保存范围，不会因登录而全部上传。
- 家庭共享、常用语同步等仅按现有账号、家庭、档案权限及同步状态工作。同步失败不应被显示为同步成功；私人图片也不会因登录自动成为公共图片。
- 同一台设备上的不同账户、工作区、档案互相隔离。浏览器清理、系统回收或清除本机数据可能移除内容，本机保存不是永久备份。

重要内容请使用对应的导出或备份入口，并核对文件确实可读取。导出文件也可能含私人信息，应自行妥善保管。

### <a name='HowdoIupdatemyuserinformation'></a>如何修改账号资料？

打开设置中的账号页，仅修改页面允许编辑的资料。图板解锁不是账号权限授权；只读的家庭共享内容不会因解锁而变成可编辑。

### <a name='HowdoIresetmypassword'></a>忘记密码怎么办？

使用当前登录页实际提供的密码找回入口；若入口不可用，请联系向你提供试用账号的负责人核实处理方式。不要把密码、验证码、API 密钥或私人照片发送给上游 CBoard 支持邮箱。本版本未在此公布新的客服渠道。

## <a name='Price'></a>费用与联网功能

### <a name='HowmuchdoesCboardcost'></a>使用是否免费？

本地选图、文字编辑、已缓存图片与已保存常用语可按当前权限使用。在线 AI、语音或其他供应商服务是否开放及是否消耗额度，以本版本入口和调用前提示为准；不能因为 CBoard 是开源项目就认为所有在线服务永久免费。

## <a name='Features'></a>功能范围

### <a name='WhatdevicesandOSaresupported'></a>支持哪些设备和浏览器？

网页版可在桌面、平板和手机浏览器访问；小程序使用独立的微信版本。当前自动验收不能代替真实手机、iOS 微信、扬声器或临床效果验证。不同浏览器和设备的语音、文件访问、缓存与权限可能不同。

离线使用需要先保存对应内容与图片，并核验图片可离线使用。“记录已保存”不等于图片文件必然可用；缺图时保留原文字和身份，由用户主动重新检查、换图或修复。

### <a name='WhichlanguagesaresupportedbyCboard'></a>如何更换语言？

打开设置中的语言选项，选择列表中可用的语言。界面语言、图卡标签和设备语音是不同设置；切换语言不会自动翻译全部私人图卡，也不能保证设备已有对应声音。

### <a name='CanCboardreadmymessageoutaloud'></a>如何朗读消息？

选择图卡或使用播报整句入口。三候选句、整句查看和接收重听沿用各自的播放规则；仅查看或恢复草稿不应自动播放。可随时停止播放。语音可用性以当前设备为准，本帮助不保证实际扬声器已验收。

### <a name='Speechcapabilities'></a>如何调整语速和声音？

在设置的语音页选择当前设备提供的声音与参数。双向沟通的“显示与易用性”也提供语速和候选句自动播报设置。修改后核对本机保存提示；页面保留的修改不等于保存成功。

## <a name='Settings'></a>设置、解锁与使用引导

### <a name='HowdoIaccesssettingsinCboard'></a>如何打开设置？

图板工具栏的锁按钮用于防止误触编辑。默认需要连续点击 **4 次** 解锁；若已启用简化解锁或 PIN，请按当前配置操作。解锁后使用工具栏的设置入口，工具栏位置以当前窗口布局为准。

解锁只改变编辑界面状态，不替代登录、家庭角色或档案授权。修改设置后核对成功／失败提示；失败时在原页面重试，勿把旧设置误认为新设置已生效。

### <a name='CanIchangeanynavigationsettings'></a><a name='Navigationthroughtheinterface'></a>导航和按钮有哪些设置？

在设置中的“导航和按钮”查看当前提供的大退格、逐项删除、分享、简化解锁、大滚动按钮及重置帮助引导等选项。按使用者需要选择，不必全部开启。应用扫描与系统辅助功能分别配置；改变按钮显示不等于改变账号权限或保存范围。

### 如何跳过或重新打开使用引导？

引导中可选择“跳过／关闭引导”或按步骤完成。需要再次查看时，在设置的“导航和按钮”中使用“重置所有帮助引导”，确认后重新进入对应图板或设置页。双向沟通的“显示与易用性”还可单独重新查看三步说明。

设置引导中的说明图片由用户用前后按钮切换，不自动翻页，可按自己的节奏停留阅读。跳过或完成后返回当前任务，引导不会替你保存沟通内容。

帮助正文随本版本加载。离线无法读取时会提示并提供重试；不要因此反复提交当前沟通内容。返回帮助前的任务后，继续核对原内容。

### <a name='HowdoIprintmyboardsetinCboard'></a>如何打印图板？

如当前工具栏提供打印入口，可在解锁后使用。打印或下载前预览内容，特别检查私人照片、姓名和家庭资料；打印不是账号同步或沟通记录确认。

### <a name='HowdoIseeCboardinfullscreen'></a>如何全屏查看？

使用当前工具栏中的全屏入口；浏览器和设备可能限制全屏。全屏与接收页的整句展示不同，返回后应保留当前内容。

### <a name='HowdoIshareaboard'></a>如何分享图板？

仅使用当前可用的分享入口，并确认分享对象和范围。公开发布图板可能让其他人查看其内容；包含私人照片、姓名或健康资料的图板不要公开发布。

### <a name='HowdoIshareaphrase'></a>如何分享整句？

如导航设置提供“显示共享短语按钮”，可按需要启用。“分享整句”分享当前确认的完整句子，不只分享正在看的阅读段。分享或复制必须主动操作；返回或取消不等于发送成功。

## <a name='Talking'></a>文字、图片与朗读

### <a name='HowdoIaddapersonallyrecordedvoicetosymbolsonCboard'></a>如何给图卡添加录音？

如当前编辑器提供录音功能，解锁图板、进入编辑、选中图卡并打开编辑器，再按录音入口操作。仅录音时需要相应麦克风权限；普通文字朗读不应要求麦克风权限。保存后核对结果，不把录音权限等同于云语音已开放。

### <a name='HowdoIswitchtoadifferentvoice'></a>如何切换声音？

打开设置中的语音页，从当前设备可用声音中选择。没有合适声音时，不会因选择而自动安装或购买新的语音服务。

### <a name='HowdoIchangehowavoicesounds'></a>如何改变语速或音调？

使用语音页提供的参数，在安全环境主动试听并停止。真实声音质量仍需人工听辨。

### 图片不足时怎么办？

完整原句供伙伴核对，保留文字不等于已经完成图示表达。否定、疑问、人物、动作等关键意思缺少合适图片时，按提示选图、补图，或由伙伴改说并辅助展示；不能把相关但不同义的图片当成正确答案。对方“不懂”时可重听、分段查看、改说或调整图片，之后重新确认。

私人照片仅使用现有个人图库和本地选择入口，不按姓名联网搜图。人物使用全名；出现重名时明确选择具体的人，不能只靠标签替换图片。

## <a name='BoardEditing'></a>编辑图板

### <a name='HowdoIcreateanemptyboard'></a>如何创建空图板？

在可编辑的图板解锁后，使用新增入口创建文件夹／图板，填写名称和封面。新图板与当前图板的关联以保存结果为准；只读共享条目不能通过此步骤取得修改权限。

### <a name='HowdoIpersonalizeanexistingboardinCboard'></a>如何修改现有图板？

解锁后进入编辑，选中图卡并使用编辑按钮。保存前核对文字和具体图片；仅更改标签不会证明旧图片仍符合新意思。

### <a name='CanIusemyownpictureswheneditingaboard'></a>能使用自己的图片吗？

可从现有个人图库或本地图片选择入口使用有权使用的图片。确认图片可读并核对保存结果；修复当前图片不会自动替换全部收藏或历史快照。私人图片不要放入公共图板、公共补图请求或模型请求。

### <a name='CanIchangetheorderingoftheelementsinaboard'></a>如何调整图卡顺序？

在原生图板编辑模式中使用已有排序操作。固定顺序与“常用优先”的设备显示顺序不同；表达里重复图卡的顺序也应保留，不按标签重新拼句。

### <a name='HowdoIselectmultipleelementstoedit'></a>如何选中多张图卡？

进入编辑模式后使用选择控件，再使用当前可用的编辑或删除入口。先核对选择范围；批量清理与单条误删撤销不具有相同恢复保证。

### <a name='FindSymbols'></a>如何寻找图片？

在图卡编辑或接收复核工作区使用现有候选、个人图库及主动补图入口。先核对含义再确认，不能仅凭相同中文／英文标签采用图片。离线重开或恢复网络不应自动运行搜索。

### <a name='FixedBoards'></a>固定图板有什么作用？

固定图板保持原行列和图卡位置；屏幕变窄时按布局规则查看，不自动把空位填满。在原生编辑工具栏使用对应选项设置固定图板。

### <a name='FixedRows'></a>如何设置行列？

先设为固定布局，再使用编辑工具栏的行列控件。双向沟通的图卡大小偏好不应重写固定图板的原始行列数据。

## <a name='Exportandimport'></a><a name='Exportandimport-1'></a>导出与导入

### <a name='HowdoIexportmyboardinCboard'></a>如何导出？

打开对应导出页，选择当前提供的图语家／CBoard、Open Board 或 PDF 等格式，核对对象与预览后保存文件。图板与常用语导出是不同入口，不代表所有草稿和账号数据都包含在文件中。

### <a name='HowdoIimportaboardintoCboard'></a>如何导入？

使用对应导入入口选择文件，先检查预览、重复项、缺图与容量，再明确确认。常用语容量不足时整批暂停，不应挤掉旧收藏；不要为导入而先清空现有资料。

### <a name='WhatfileformatdoesCboarduseforimportexport'></a>支持什么格式？

以当前导入页列出的格式为准。图语家／CBoard 与 Open Board 文件的数据范围可能不同；导入后仍须核对原句、图片顺序和人物身份。无法读取的图片应明确处理，不按同名人物替换。

## <a name='Displaycapabilities'></a><a name='Displaycapabilities-1'></a>显示与易用性

### <a name='WhatcanIchangeonthedisplay'></a>可以修改哪些显示设置？

显示页提供 CBoard 全局显示选项；双向沟通的“显示与易用性”复用相应字号、图卡大小和高对比度等配置。界面选中状态与本机保存提示分别核对，颜色不是唯一提示。

### <a name='CanIresizebuttonsonCboard'></a>能调整按钮和字体大小吗？

使用当前显示设置选择大小。大字号下长句和长标签应可完整查看，不能把省略标签当成完整原句；可使用“查看整句”。

### <a name='BigScrollButtons'></a>如何启用大滚动按钮？

如当前导航设置提供大滚动按钮，可按需要开启并保存。仅内容确实可滚动时才需要滚动，不应依赖滑动才能找到唯一返回按钮。

## <a name='Scanning'></a>扫描访问

### <a name='CanIusescanningtechniquestoaccesssymbols'></a>如何使用扫描选择？

在扫描页配置启用状态、自动／手动方式、选择键和速度。当前版本复用 CBoard 扫描器；弹窗、隐藏页面与输入时的扫描状态按现有规则处理。应用扫描与操作系统开关控制、屏幕阅读器是不同能力，需分别验收；本帮助不宣称真实辅助设备已经测试。

## <a name='CommunicatorBuilder'></a>图板管理

### <a name='Whatiscommbuilder'></a>什么是图板管理？

解锁后通过当前工具栏的图板管理入口管理本沟通器使用的图板。可用标签与动作受账号、权限、网络及版本限制。

### <a name='CommunicatorBoards'></a>沟通器中的图板

可按当前权限添加、移除或设置根图板。“从沟通器移除”通常是解除当前关联，与永久删除不同；操作前核对说明。

### <a name='PublicBoards'></a>公共图板

公共图板用于有权公开分享的素材。复制后核对来源、含义与图片可用性；不要把私人照片、姓名或家庭资料发布到公共图板。

### <a name='Allmyboards'></a>我的图板

可用内容受当前账号与权限限制。公开发布、取消发布、从沟通器移除和删除是不同操作，先阅读确认提示。不要因为本机有撤销入口就假定永久删除或隐私清理也能撤销。
