# 图语家 iPad 离线展台候选

2026-10-12，Codex；原派发 `20261011T180018-6f3c92`。本轮保留模型、思考强度和速度，未做覆盖。独立候选入口复用 CBoard 的真实沟通输出及现有 `sw-precache`，不加载账号、患者档案或业务后台。

## 使用与交付

- 构建：在 `D:/used-by-codex` 执行 `node fork-cboard/cboard/exhibit/build.cjs`。
- 定向测试：`node fork-cboard/cboard/exhibit/exhibit.test.cjs`。使用已有 jsdom 和 node:test，不安装新依赖。
- 候选：`D:/used-by-codex/outputs/tuyujia-ipad-booth-20261012/site/index.html`。本地文件能预览界面，离线安装需要 HTTPS 或本机 loopback 地址。
- 默认构建仅写隔离 outputs 目录。项目已有改动保持原状；本轮未提交或推送 Git，未部署公网。
- 临时预览脚本仅监听 `127.0.0.1:18778`，固定映射 `/exhibit/` 到候选目录；不提供目录列表、后台接口或网络转发。测试结束已停止。重跑前需确认同端口空闲、删除本次测试的 `stop-preview` 标记，再启动 `preview.cjs`；应沿用有时限的监测包装器。

## iPad 待验收步骤

1. 部署批准后，将 `site` 的完整内容放到独立目录，例如现有官网的 `/exhibit/`；使用 HTTPS，并确认已有根 Service Worker 不拦截该目录。不要只拷贝 index.html。
2. iPad Safari 联网打开地址，等“离线资源已核验”；查看资源版本与本轮报告一致。
3. 分享 → 添加到主屏幕。从主屏幕重新打开并再次检查离线资源。普通标签页与主屏幕入口的存储不能直接视为已互通。
4. 关闭 Wi-Fi 和移动数据，关闭 Safari/主屏幕应用后重开；分别测试三组图片、配对、确认、重选、下一组及示例模式。
5. 记录 iPad 型号、iPadOS/Safari 版本、是否主屏幕入口、图片是否齐全及操作结果。再测试设备重启后打开。
6. 每次展会前重新检查。浏览器可能清理存储；现场保留纸卡后备。不能承诺永久缓存。

## 已支持的范围

预设句子点选查看项目实际运行结果；图片与句子配对；由表达者确认或重选；完整依赖预缓存、逐文件校验、明确更新按钮、资源缺失提示。图片区域只有原图，句子独立显示。

不支持任意文本实时输入转换、图片识别生成句子、云端 AI、登录、云同步。配对答案由人选择，不能称为逆向 AI 推理；不收集观众信息。页面重新打开后练习状态归零，资源仍从缓存加载。
