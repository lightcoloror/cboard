## 实现决定

| 意图 | 决策 | 理由 | 证据 | 生效范围 |
|---|---|---|---|---|
| 保存须可确认、失败可重试 | 复用 Redux/localForage/getStoredState：store 绑定、队列、flush 后严格读回、完整快照核验，稳定 ID 与 scope guard | 派发/flush 完成不能证明落盘；旧回执不能覆盖新状态 | `gallery-storage-implementation.md`、正式三类故障 | 个人图库创建/人物/公开收纳/移除；原 action 语义不变 |
| 熟悉照片读取出错不覆盖旧列表 | 严格预读原格式，保留候选照片供重试 | 坏 JSON/非数组/读取异常不能当空库 | `gallery-preference-persistence-implementation.md` | 现有熟悉图片偏好存储，不新增图库 DB |
| 导入/删除/撤销后立即反映已保存结果 | 已提交回调严格重读规范仓库；待写变化继续 CAS | 第二次用旧 React 列表写入造成假冲突 | `core/favorites-committed-refresh-fix.md`、正式核心 | 常用语三个已提交动作 |
| 新匹配公共图片可显示且恢复不隐式联网 | 仅用户主动匹配时准备白名单包内图片，解码→现有缓存→读回；历史恢复维持 local-only | v1 冷缓存两个图片引用存在但没有显示 | `core/README-gallery-durable-v2.md`、`receiver-public-cache-tests.log` | 包内公共图；不改变原句/人物身份，不上传私图 |
| WebKit 原站失败时语言回退正常 | 把 push 返回的长度改为新语言数组 | 真实出现 langs.sort 错误 | `webkit/language-fallback-before.log`、`webkit/v2-summary.json` | 语言资源失败回退 |

定向测试批次分别为核心存储 32、图库 UI 72、偏好相关 132、常用语刷新 65、公共图缓存相关 55、语言 8 项通过；文件存在交叉，**不相加为独立总数，也不计作新增端到端通过数**。本轮未跑全套测试。模块缺失、fixture 缺字段、测试定位/crypto 别名、旧 WebKit 缓存模拟故障均保留原证据，不计为新产品缺陷。
