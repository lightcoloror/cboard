# 图语家 Web 患者协作接入

更新时间：2026-09-13 20:14:08（Asia/Shanghai）
实现与整理：Codex（GPT-6 Astra）

## 入口与依赖

构建开关 `REACT_APP_CARE_COLLABORATION=true`。同时使用本轮 cboard-api（CARE_COLLABORATION_ENABLED、CARE_NEXT_ENABLED），未发放的测试订阅不会自动产生真实权益。无需另建账号。

已登录主页和图板入口进入 `components/Care/CareHome.js`，复用 CommunicationSupportPanel：患者默认图片表达，家属默认接收。设置图标进入共享 CarePanel，管理档案、权限、设备、收藏、恢复、额度来源。多档案账号优先使用服务端已选择且仍可访问的档案；身份和数据权限独立。

本地同步由 careSync、careProjection、careMediaValues 承载；全局同账号/家庭/患者键隔离，个人收藏另按账号隔离。可用时 Web Locks 协调同源浏览器标签；平台不支持时保留进程内序列化。退出或切换账号先移除旧投影。旧设置合并、接收记录上传和 AI 请求不会带上普通历史。

## 离线与恢复操作

协作设置中选择患者，输入备份密码，再点击“加密导出到另一设备”。在空白设备的协作设置页选择离线归档、输入密码并核对来源，恢复后回到主沟通界面。恢复不授予云端权限；需要云端时先登录，再选择同一患者导入。来源不同会停止覆盖，没有“复制到另一患者”入口。旧格式仍走来源预览。

临时断网保留资料和队列；重新登录、订阅到期、撤权是不同状态。只有真正撤权锁定档案；到期不禁止本地沟通和导出。重复恢复不会重复创建资源。保存中的家庭共享及成员原收藏更新各自保留版本和结果，失败项可重试或保留原版本。
